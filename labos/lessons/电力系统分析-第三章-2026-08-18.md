# 电力系统分析 第三章《潮流计算》教案


## 一、教学目标

### 知识目标
1. 掌握潮流计算的基本概念、物理意义及其在电力系统分析中的地位。
2. 理解并推导节点导纳矩阵的构成原理与形成方法。
3. 掌握潮流计算的基本方程（节点功率方程）及其变量分类。
4. 理解牛顿-拉夫逊法（Newton-Raphson）和快速解耦法（P-Q分解法）的基本原理与迭代格式。
5. 了解潮流计算中PV、PQ、平衡节点的类型与作用。

### 能力目标
1. 能够独立建立简单电力网络的节点导纳矩阵。
2. 能够手动完成2~3节点系统的牛顿-拉夫逊法潮流计算迭代过程。
3. 能够利用MATLAB/Python编写简单的潮流计算程序框架。
4. 能够分析潮流计算结果，判断系统电压水平与功率分布合理性。

### 素养目标
1. 培养工程思维：从物理模型到数学模型的抽象能力。
2. 培养严谨的计算习惯与误差控制意识。
3. 认识潮流计算在电网规划、运行调度中的实际工程价值，增强专业使命感。


## 二、教学重难点

### 重点
1. 节点导纳矩阵的形成与修改规则。
2. 潮流计算方程的建立与变量分类（扰动变量、控制变量、状态变量）。
3. 牛顿-拉夫逊法的基本原理及直角坐标/极坐标下的迭代格式。

### 难点
1. 节点导纳矩阵的稀疏特性及其在工程中的利用。
2. 牛顿-拉夫逊法中雅可比矩阵（Jacobi Matrix）的推导与修正方程的建立。
3. P-Q分解法对牛顿法的简化思路及适用条件。

## 四、教学过程

### （一）导入（5 min）

**提问式导入：**
- “假设你是某省电网调度员，清晨6点，面对全省数百个变电站，你是否知道此刻每条线路的功率是多少？每个节点的电压是多少？”
- “如何用计算机快速算出全网各节点的电压和功率分布？”
- 引出：这就是**潮流计算（Power Flow Calculation）** 的任务。

**教学意图：** 建立直观工程背景，激发学习兴趣。


### （二）新课讲授（60 min）

#### 1. 潮流计算概述（5 min）

- **定义：** 在给定电网结构、参数和发电机/负荷功率的条件下，计算各节点电压幅值、相角及各支路功率分布。
- **地位：** 电力系统最基础、最频繁的计算工具——用于规划、运行、稳定分析等。
- **发展历程：** Gauss-Seidel法 → Newton-Raphson法 → P-Q分解法 → 现代人工智能辅助方法。

#### 2. 节点导纳矩阵（15 min）

- **定义：** 描述网络拓扑与参数的复导纳矩阵Y。
- **自导纳Y_ii：** 与节点i相连的所有支路导纳之和（含对地导纳）。
- **互导纳Y_ij：** 节点i、j之间支路导纳的负值。
- **形成规则：** 节点电压法列写节点方程 → 整理成矩阵形式。
- **例题（板书）：** 3节点系统（含变压器支路，变比1.05:1），列写Y矩阵。

**强调：** Y矩阵的稀疏性（大型电网中每行平均非零元素不超过5个）。

#### 3. 潮流方程与变量分类（10 min）

- **节点功率方程（极坐标形式）：**

$$P_i = V_i\sum_{j=1}^{n}V_j(G_{ij}\cos\theta_{ij} + B_{ij}\sin\theta_{ij})$$

$$Q_i = V_i\sum_{j=1}^{n}V_j(G_{ij}\sin\theta_{ij} - B_{ij}\cos\theta_{ij})$$

- **变量分类：**
  - 扰动变量：PQ节点的P、Q（负荷）
  - 控制变量：PV节点的P、V（发电机）
  - 状态变量：各节点V、θ（待求量）

- **节点类型：**
  | 节点类型 | 已知量 | 待求量 |
  |---|---|---|
  | PQ节点 | P, Q | V, θ |
  | PV节点 | P, V | Q, θ |
  | 平衡节点 | V, θ（通常θ=0） | P, Q |

#### 4. 牛顿-拉夫逊法（20 min）⭐

- **基本原理：** 多元非线性方程组的线性化迭代求解。

- **修正方程：**

$$\begin{bmatrix}\Delta P \\ \Delta Q\end{bmatrix} = -\begin{bmatrix}H & N \\ K & L\end{bmatrix}\begin{bmatrix}\Delta\theta \\ \Delta V/V\end{bmatrix}$$

- **雅可比矩阵各子块含义：**
  - H：P对θ的偏导
  - N：P对V的偏导
  - K：Q对θ的偏导
  - L：Q对V的偏导

- **迭代步骤：**
  1. 给定初值（V⁰=1.0，θ⁰=0）
  2. 计算功率偏差ΔP、ΔQ
  3. 判断是否收敛（|ΔP|, |ΔQ| < ε）
  4. 求解修正方程得Δθ、ΔV
  5. 修正：θ⁽ᵏ⁺¹⁾ = θ⁽ᵏ⁾ + Δθ，V⁽ᵏ⁺¹⁾ = V⁽ᵏ⁾(1+ΔV/V)
  6. 重复直至收敛

- **特点：** 二次收敛速度快，但对初值敏感。

#### 5. P-Q分解法（10 min）

- **简化思路：**
  - 高压电网中，X >> R，有功主要与θ相关，无功主要与V相关
  - 忽略N、K子块 → 两个低阶方程组：
    - ΔP/V = B′·Δθ
    - ΔQ/V = B″·ΔV
  - B′、B″为常数矩阵，只需一次三角分解即可反复使用

- **优点：** 计算速度快，内存占用小，适合在线计算。
- **适用条件：** 高压输电网（R/X较小），且正常运行状态。


### （三）练习/讨论（15 min）

**练习1（手算）：** 2节点系统
- 节点1：平衡节点（V=1.0∠0°）
- 节点2：PQ节点（P=-0.8pu，Q=-0.6pu）
- 线路：Z = j0.1pu
- 要求：进行一次牛顿迭代，求节点2的V和θ。

**讨论：**
- 如果线路电阻R不可忽略，P-Q分解法还适用吗？为什么？
- 潮流计算不收敛可能是什么原因？（初值不当、系统接近电压崩溃点、数据错误等）

- 知识框架回顾（板书思维导图式总结）
- 强调：Y矩阵→功率方程→牛顿法→P-Q分解法→工程应用
